# 02: Home Navigation

**What to build:** A Home Navigation row under the Status Bar with Início, Explorar and Todos os apps, as in `docs/design/home-navigation.png`.
- The section the owner is in is highlighted.
- Pressing up from the App Tray reaches the row.
- **Início** is today's Home. **Todos os apps** opens All Apps. **Explorar** opens an Explorar screen that, until ticket 03, only shows the row with Explorar highlighted.
- Back from Explorar returns to Início, and the Home button always lands on Início.
- The Top Shelf and the Edit Mode hint keep their places below the row.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] The row matches the design on Início and Explorar, with the current section highlighted
- [ ] Up from the App Tray reaches the row; left and right move along it; OK switches sections
- [ ] Todos os apps opens All Apps; Back from Explorar returns to Início; Home lands on Início
- [ ] Nothing on Início moves into the row's space (Top Shelf, Edit Mode hint)
